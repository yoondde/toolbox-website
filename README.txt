TOOLBOX 웹사이트

구성
- index.html: 반응형 웹사이트와 6개 브라우저 기반 도구
- 외부 라이브러리/서버 없이 작동

무료 배포
1. https://github.com 에서 계정을 만들고 새 Public repository를 생성합니다.
2. 이 폴더의 index.html을 저장소 최상단에 업로드합니다.
3. 저장소 Settings > Pages > Deploy from a branch > main / root를 선택하고 Save 합니다.
4. 잠시 기다리면 https://계정이름.github.io/저장소이름/ 주소로 공개됩니다.

수익화 준비
- 광고 영역은 위치 표시용이며 아직 실제 광고가 아닙니다.
- Google AdSense에 사이트를 등록하고 심사를 신청해야 합니다.
- 승인 후 발급받은 광고 스크립트와 광고 단위를 실제 광고 영역에 넣어야 합니다.
- 승인 및 수익은 보장되지 않습니다. 독창적인 설명/가이드, 문의처, 개인정보처리방침, 이용약관을 실제 정보로 보완하세요.
- 방문자 유입을 위해 도구별 상세 사용법과 검색에 유용한 고유 콘텐츠를 꾸준히 추가하세요.
- 광고 클릭을 유도하거나 본인이 광고를 클릭하면 안 됩니다.

주의
- 이미지 변환/압축과 텍스트 처리는 사용자의 브라우저 안에서 실행됩니다.
- 사이트를 실제 운영하기 전에 브라우저와 모바일에서 기능을 테스트하세요.
